# Warcraft Audi

Озвучка квестов для **WoW Circle Dragonflight 10.2.7**, Interface `100207`.
Текущая версия — проверочный комплект **аддон + программа для Windows 10/11 x64**.
Аудио скачивается по необходимости; большой каталог квестов на компьютер не устанавливается.

**[Скачать комплект 0.4.0 для Windows — около 18 МБ](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/WarcraftAudi-Companion-0.4.0-Windows.zip)**

## Первый запуск

1. Полностью распакуйте ZIP, закройте WoW.
2. Скопируйте папку `AddOns/WarcraftAudi` из комплекта в `Interface/AddOns`
   вашего клиента, заменив основной аддон.
3. Запустите `Start.bat`. Python отдельно устанавливать не нужно.
4. В открывшемся окне нажмите **«Проверить голос»**.
5. В игре выполните **`/wca companion`** — появится небольшой индикатор.
6. В программе нажмите **«Выделить индикатор на экране»**, за 3 секунды
   переключитесь в WoW. Подождите снимка, вернитесь, выделите индикатор вместе
   с цветными углами и сохраните область.
7. Нажмите **«Запустить»**, вернитесь в игру и откройте квест.

Для первой проверки нужен оконный режим без рамки и видимый индикатор.
Его можно переместить мышью; после перемещения нужна новая калибровка.
[Полная инструкция, архитектура и границы проверки](docs/COMPANION.md).

## Что уже подготовлено

- Передача реального текста, ID, этапа и сведений о NPC через экранный индикатор.
- Контроль целостности и сборка многостраничных сообщений; повреждённые кадры
  не запускают случайное аудио.
- Скачивание готовых записей, проверка SHA-256, воспроизведение вне игры.
- Локальный LRU-кэш **300 МБ** с автоматическим удалением старых записей.
- Серверная очередь генерации, объединение одинаковых запросов и общий кэш.
- Голосовой эталон на NPC: Акунда использует утверждённую пробу 0.3.0.
  Голос подбирается под внешность конкретного персонажа; бас Акунды не переносится
  на остальных. Для Киро проба 0.4.1 отвергнута как слишком басовая и заменена
  голосом 0.4.2 в более высоком регистре, принятым пользователем.
  Для других NPC сервер может создавать и сохранять кандидатов по доступным
  сведениям. Художественное соответствие внешности требует проверки.

**Без собственного сервера доступны опубликованные записи Акунды и
«Природного лекарства» (48313) от Киро.** [Обновление Киро](docs/QUEST_48313.md).
Новые квесты требуют сервер генерации: код и локальная работа проверены,
но публичный сервер ещё не развёрнут. По договорённости сначала проверяем
Windows-программу в игре, затем выбираем хостинг. Эта версия не обещает
озвучку всех неизвестных квестов сразу после скачивания ZIP.

## Команды аддона

| Команда | Действие |
| --- | --- |
| `/wca companion` | Включить/выключить внешнюю программу |
| `/wca` | Панель повтора и остановки |
| `/wca demo` | Проба голоса через выбранный режим |
| `/wca read` | Прочитать выбранное задание из журнала |
| `/wca play` / `/wca stop` | Повтор / остановка |
| `/wca auto` | Автозапуск реплики |
| `/wca export` | Экспорт собранных текстов в JSON |
| `/wca collect` | Включить/выключить сбор текстов |

SavedVariables сохраняются при штатном выходе или `/reload`.
Снимки экрана остаются на компьютере игрока. Сервер получает текст и сведения
о NPC. Полный клиентский кэш и настройки: `%LOCALAPPDATA%/WarcraftAudi`.

## Разработка

Работайте в существующем checkout: облачная задача уже изолирована,
дополнительный Git worktree не нужен.

```sh
python -m pip install -r companion/requirements.txt
python -m pip install lupa==2.6
python -m unittest discover -s tests -v
python -m companion
```

В подготовленной облачной машине используйте `/workspace/.warcraft-audi-venv/bin/python`.
Lupa исполняет настоящий Lua 5.1 код с имитацией WoW API. Без Lupa/Pillow
соответствующие тесты пропускаются; пропуски не подтверждают готовность.
Браузерные проверки явно используют синтетический экран, не настоящий WoW.

[Запуск сервера](server/README.md). [Протокол и результаты проверок](docs/COMPANION.md).
Сборщик Windows: `tools/build_companion_windows.py`. Он проверяет подпись Sigstore
официального CPython и SHA-256 Windows wheels из PyPI. Моделей в клиентском ZIP нет.
Сервер использует Qwen VoiceDesign и Base; веса хранятся вне Git и проверяются
по SHA-256 закреплённых версий из `voices/models.json`.
