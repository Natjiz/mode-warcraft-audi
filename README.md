# Warcraft Audi

**[Скачать готовый ZIP с озвучкой Акунды](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/WarcraftAudi-0.2.0-Akunda.zip)**

Закройте WoW, распакуйте обе папки из архива в `Interface/AddOns`, включите оба
аддона и введите `/wca demo`. Это установочный архив; собирать проект не нужно.

Аддон для **WoW Circle Dragonflight 10.2.7**, Interface `100207`.
**Версия 0.2.0 содержит готовые речевые файлы для одного квеста:
«Благословение Акунды», ID 50913.** Озвучены выдача, прогресс и завершение.
Описание выбирает обращение по полу персонажа. Голос синтетический, Silero v5
(eugene, профиль `loa`); его подачу нужно оценить на слух.
Другие квесты пока без записей. [Генерация озвучки](docs/GENERATING_AUDIO.md).
Совместимость API проверена по исходникам интерфейса Blizzard 10.2.7;
проверка в самом клиенте WoW Circle ещё требуется.

## Что работает в аддоне

- Выбор записи по языку клиента, ID квеста и этапу: выдача (`detail`),
  прогресс (`progress`), завершение (`complete`).
- Автоматическое последовательное воспроизведение нескольких файлов без наложения.
- Повтор, остановка, отключение автозапуска; остановка при закрытии диалога.
- Сбор увиденных текстов, имён NPC и их ID, экспорт в JSON для подготовки записей.
- Отдельные голосовые пакеты: их можно выпускать по зонам и постепенно пополнять.

Аддон не вызывает внешние API и не синтезирует речь внутри игры. Готовые MP3/OGG
лежат в папках голосовых пакетов. Тексты других квестов, ещё не открытых у NPC,
автоматически не загружаются. Для покрытия всех квестов нужен полный каталог
именно серверной версии, включая изменённые Circle тексты, и подготовленные записи.
Голосовые пакеты поддерживают поле `gender`: `male` или `female`; проигрыватель
выбирает его через `UnitSex("player")`, затем ищет общий вариант. Автоматический
экспорт пока хранит последнюю увиденную версию этапа без разделения по полу/расе.

## Установка

1. Соберите архив с готовыми записями: `python3 tools/build_akunda.py`.
   Повторный синтез и модель для этой сборки не нужны.
2. Полностью закройте клиент WoW.
3. Распакуйте **обе папки** из `dist/WarcraftAudi-0.2.0-Akunda.zip`
   в папку аддонов используемого клиента: `WarcraftAudi` и `WarcraftAudi_Akunda_ruRU`.
   Получится `Interface/AddOns/WarcraftAudi/WarcraftAudi.toc`. Не добавляйте
   лишний уровень вложенности. В некоторых установках путь начинается с `_retail_`.
4. Включите **Warcraft Audi** в списке модификаций. Установленные пакеты голосов
   должны быть включены рядом с основным аддоном.
5. В настройках звука WoW включите звук и канал **«Диалоги»**.
6. Введите **`/wca demo`**: прозвучит мужская версия описания квеста даже вне
   диалога с NPC. У самого NPC нужный этап звучит автоматически.

В архиве есть `INSTALL-RU.txt`. Сборщик `tools/package_addon.py addon` создаёт
только основной аддон; для полной пробы используйте `build_akunda.py`.

Команды:

| Команда | Действие |
| --- | --- |
| `/wca` или `/waudi` | Открыть панель |
| `/wca play` | Повторить реплику текущего этапа |
| `/wca demo` | Прослушать описание «Благословения Акунды» вне диалога |
| `/wca stop` | Остановить |
| `/wca auto` | Включить/выключить автозапуск |
| `/wca export` | Открыть JSON для копирования через Ctrl+A, Ctrl+C |
| `/wca collect` | Включить/выключить сбор текстов |

Панель можно перетаскивать мышью. При отсутствии записи аддон сообщает об этом,
а текст сохраняется для экспорта, если сбор включён. Сохранение на диск происходит
при штатном выходе или `/reload`, как у обычных SavedVariables WoW.
Данные находятся в `WTF/Account/<аккаунт>/SavedVariables/WarcraftAudi.lua`.
Экспорт может содержать имя вашего персонажа в репликах; просмотрите его перед передачей.

## Подготовка голосового пакета

Откройте несколько квестов, экспортируйте тексты и сохраните их в UTF-8 как
`quests.json`. Запишите или сгенерируйте реплики вне игры. Для каждой готовой
реплики заполните `audio` относительными путями к файлам в нужном порядке:

```json
{
  "schema_version": 1,
  "quests": [
    {
      "quest_id": 12345,
      "locale": "ruRU",
      "stage": "detail",
      "title": "Название из реального экспорта",
      "speaker": "Имя NPC",
      "text": "Текст из реального экспорта",
      "audio": ["ruRU/12345/detail_01.ogg", "ruRU/12345/detail_02.ogg"]
    }
  ]
}
```

Это пример схемы, а не готовая запись существующего квеста. Этапы с пустым `audio`
пропускаются. Пути файлов должны содержать латиницу; допускаются MP3 и OGG
(для OGG используйте Vorbis, не Opus). Сборщик проверяет пути и заголовки файлов,
но не декодирует звук: прослушайте финальные записи и проверьте их в WoW.

```sh
python3 tools/package_addon.py pack quests.json \
  --audio-root /path/to/recordings --name Dragonflight_ruRU \
  --output dist/WarcraftAudi_Dragonflight_ruRU.zip
```

Распакуйте пакет рядом с основным аддоном и перезапустите клиент. Пакет объявляет
зависимость от `WarcraftAudi`. Пересечения одного языка/ID/этапа между пакетами
отклоняются целиком с сообщением в чате; не устанавливайте перекрывающиеся пакеты.
Имя NPC в экспорте помогает выбрать голос, но поиск записи идёт по ID квеста.

## Разработка и проверки

Для сборки архивов нужен только Python 3.10+. Сам аддон использует Lua 5.1
и штатные API WoW; сервер, БД и ключи API для него не нужны.
Для генерации аудио вне игры дополнительно нужны CPU PyTorch и FFmpeg.
Используйте существующий checkout: облачная задача уже изолирована, дополнительный
Git worktree не требуется.

```sh
python3 -m unittest discover -s tests -v
python3 tools/build_akunda.py
```

Тесты проигрывателя выполняют настоящие Lua-файлы через **Lupa 2.6 / Lua 5.1**
с имитацией WoW API. Для них установите `python3 -m pip install lupa==2.6`
в своё виртуальное окружение. Без Lupa эти тесты отмечаются как skipped.
Сборщик проверяется без сторонних зависимостей. Эти проверки не заменяют
проверку интерфейса и звука в WoW Circle: [чек-лист](docs/CLIENT_TEST.md).

Ориентиры будущей озвучки: [постановка голосов](docs/VOICE_DIRECTION.md).
