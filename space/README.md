# Warcraft Audi — общая генерация квестов

Space запускает два JSON API: `/lookup` (без GPU) и `/generate`.
Windows-программа использует их автоматически, открывать эту страницу не нужно.
Готовые записи и эталоны NPC сохраняются в отдельном публичном HF dataset,
поэтому перезапуск Space не требует повторного синтеза уже созданного текста.

Переменная `WCA_LIBRARY_REPO`: `owner/warcraft-audi-library`.
Секрет `HF_TOKEN`: запись в этот dataset. Не добавляйте секрет в исходники.
Выберите бесплатный ZeroGPU; CPU/платная GPU-машина автоматически не заказывается.
Доступность бесплатного размещения зависит от условий Hugging Face для аккаунта.

Веса Qwen закреплены по revision/SHA-256 и скачиваются при первом запуске.
Оба типа модели размещаются на CUDA при старте для ZeroGPU; вызов синтеза
ограничен 120 секундами и выделяет GPU только после промаха общей библиотеки.
Очередь ограничена 16 задачами, одновременно создаётся одна запись.

Эталоны Акунды и Киро утверждены пользователем. Новые профили по расе/типу/полу
являются кандидатами; отсутствие данных о внешности не считается подтверждением
соответствия образу. Публикуются канонический текст и сведения NPC; имя игрока
обрабатывается клиентским протоколом, изображения не передаются.

Gradio 6.16.0 — совместимая с закреплённым Qwen/Transformers версия. Используются
только JSON-компоненты, без Audio/FileExplorer и без приёма путей к файлам.
При обновлении Gradio нужно повторно проверить совместимость huggingface-hub.
