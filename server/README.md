# Сервер озвучки Warcraft Audi

Публичный экземпляр ещё не развёрнут. Ниже — проверенный способ запуска из
исходников на машине с Python, FFmpeg и моделями. Клиентский Windows ZIP
моделей не содержит; вычисления выполняет этот сервер.

Рабочая директория — корень репозитория.

```sh
python -m venv /path/to/server-venv
/path/to/server-venv/bin/python -m pip install \
  --index-url https://download.pytorch.org/whl/cpu 'torch==2.6.0+cpu' 'torchaudio==2.6.0+cpu'
/path/to/server-venv/bin/python -m pip install -r server/requirements.txt
/path/to/server-venv/bin/python tools/fetch_voice_models.py --root /path/to/models
/path/to/server-venv/bin/python -m companion.warcraft_audi.server \
  --engine qwen --models /path/to/models --cache /path/to/server-cache
```

CPU-рецепт использован в проверке. Для GPU устанавливайте совместимую с сервером
CUDA-сборку PyTorch вместо CPU-пакетов. Воркер выбирает CUDA при доступности,
иначе CPU. В памяти остаётся одна большая модель; для другого типа модели
предыдущая освобождается. GPU-производительность здесь не измерена. CPU на
4 ядрах пригоден для проверки, но первая реплика может занимать минуты.

Пример проверки внутри машины:

```sh
curl http://127.0.0.1:8765/health
```

Для внешнего доступа задайте `WCA_SERVER_TOKEN` через защищённые настройки
хостинга, слушайте нужный интерфейс через `--host` и поставьте HTTPS reverse
proxy перед сервисом. При внешнем bind без ключа сервер откажется запускаться.
Не передавайте ключ через URL и не добавляйте его в репозиторий. В программе
игрока указываются HTTPS-адрес и ключ; ключ в аддон не попадает.

API:

- `GET /health`: готовность HTTP-процесса.
- `GET /v1/info`: версия библиотеки и доступность генерации.
- `POST /v1/quests`: текст/ID/этап/язык/пол и сведения о NPC; ответ с ID задачи.
- `GET /v1/jobs/{id}`: queued/generating/ready/failed/missing/expired.
- `GET /v1/audio/{id}`: готовая запись; метаданные задачи содержат SHA-256.

`/health` не подтверждает GPU, загруженные модели или работающий синтез.
Готовность синтеза проверяется настоящим POST и декодированием результата.
Одинаковые запросы объединяются. Воркер один, очередь ограничена 16 запросами;
кэш по умолчанию 10 GiB и вытесняет старые записи. Внешние клиенты не управляют
путями файлов и командами на сервере. В логах нет ключей и полных текстов квестов.

Карточки утверждённых NPC: `voices/npcs`. Новые автоматические эталоны:
`voices/generated` (не коммитятся). Они сохраняются между перезапусками и
помечены как кандидаты для последующей оценки. Данные `voices/generated` и
серверный кэш нужно хранить на постоянном диске при переносе между контейнерами.

## Бесплатный ZeroGPU-адаптер

Отдельный Gradio-адаптер с общей постоянной библиотекой, профилями NPC и
автоподключением клиента находится в `space_runtime/` и `space/`. Он подготовлен
для PyTorch 2.8, не требует ручного ввода адреса игроком и пока не размещён
из-за отсутствия подключённого HF-аккаунта. [Размещение и проверки](../docs/ON_DEMAND.md).
