# Warcraft Audi 0.5.0 — автоматическое подключение

**[Скачать программу и аддон для Windows 10/11 x64, около 18 МБ](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/WarcraftAudi-0.5.0-Windows.zip)**.

1. Полностью распакуйте архив. При закрытой игре замените папку аддона
   `Interface/AddOns/WarcraftAudi` папкой `AddOns/WarcraftAudi` из архива.
2. Откройте `WarcraftAudi.exe`, запустите игру и откройте квест у NPC.

Программа работает в отдельном окне Windows. Браузер и выделение области
не нужны; поиск и подключение начинаются сразу. Окно можно свернуть.
Оконный режим без рамки нужен для чтения автоматически появляющегося
сигнала аддона. После закрытия диалога сигнал исчезает.
Громкость, лимит кэша и сервер — в необязательных «Настройках».

Готовые озвучки: Акунда и «Природное лекарство» от Киро.
[Утверждённый голос Киро 0.4.2](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/Kiro-character-voice-0.4.2.mp3).
Предыдущая басовая проба Киро отвергнута и исключена из каталога.
Публичный сервер генерации неизвестных квестов пока не развёрнут.

[Описание и проверки](../docs/COMPANION.md). [Сборка](../docs/BUILD_WINDOWS.md).

## Исходная сборка 0.2.0

[Скачать WarcraftAudi-0.2.0-Akunda.zip](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/WarcraftAudi-0.2.0-Akunda.zip)

Это архив для установки, включающий основной аддон и русские аудиозаписи
«Благословения Акунды» (50913). Другие квесты пока без озвучки.

1. Полностью закройте WoW.
2. Распакуйте обе папки из ZIP в `Interface/AddOns` используемого клиента 10.2.7.
3. Включите оба аддона и звуковой канал «Диалоги» в игре.
4. Введите `/wca demo`, чтобы услышать запись без открытого квеста.

Внутри архива находится `INSTALL-RU.txt`. Работа в клиенте WoW Circle ещё
требует проверки; голос синтетический и предназначен для первой пробы.
