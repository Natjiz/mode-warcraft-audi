# Готовая сборка

Обновление готового каталога: «Природное лекарство» (48313) от Киро.
[Новая проба Киро 0.4.2 — лёгкий тенор](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/Kiro-character-voice-0.4.2.mp3).
Предыдущая проба Киро 0.4.1 отвергнута как слишком басовая и убрана из каталога.
Для загрузки записей переустанавливать программу не нужно: завершите её,
запустите `Start.bat` снова, нажмите «Запустить», выберите квест в журнале
и введите `/wca read`.

## Программа и аддон для Windows — 0.4.0

[Скачать переносимый комплект, около 18 МБ](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/WarcraftAudi-Companion-0.4.0-Windows.zip).

Распакуйте архив целиком. При закрытой игре замените основной аддон папкой
`AddOns/WarcraftAudi` из комплекта и запустите `Start.bat`. Сначала нажмите
«Проверить голос», затем в игре включите `/wca companion` и выполните выбор
индикатора по подсказкам программы. Кэш ограничен 300 МБ и очищается автоматически.

Проверяем работу на Windows и в реальном WoW Circle; это ещё не проверено в
облачном окружении. Без публичного сервера доступны готовые записи
Акунды и «Природного лекарства» от Киро. Хостинг генерации новых квестов
выбираем после этой проверки.
Полная инструкция — внутри ZIP и в [docs/COMPANION.md](../docs/COMPANION.md).

## Исходная сборка 0.2.0

[Скачать WarcraftAudi-0.2.0-Akunda.zip](https://github.com/Natjiz/mode-warcraft-audi/raw/refs/heads/main/downloads/WarcraftAudi-0.2.0-Akunda.zip)

Это архив для установки, включающий основной аддон и русские аудиозаписи
«Благословения Акунды» (50913). Другие квесты пока без озвучки.

1. Полностью закройте WoW.
2. Распакуйте обе папки из ZIP в `Interface/AddOns` используемого клиента 10.2.7.
3. Включите оба аддона и звуковой канал «Диалоги» в игре.
4. Введите `/wca demo`, чтобы услышать запись без открытого квеста.

Внутри архива находится `INSTALL-RU.txt`. Работа в клиенте WoW Circle ещё
требует проверки; голос синтетический и предназначен для первой пробы.
