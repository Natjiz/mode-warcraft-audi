# Бесплатное хранение и тест генерации

Проверено по официальной документации 3 ноября 2026. Пользователь предложил
хранение на GitHub и бесплатное размещение вместо обязательной аренды сервера.
Это выбор направления исследования, не разрешение на подключение платных услуг.

## Хранение

Код и небольшой каталог остаются в публичном GitHub-репозитории. Крупную
растущую библиотеку записей лучше распространять через GitHub Releases.
Документация указывает до 1000 assets на релиз, каждый меньше 2 GiB;
совокупный размер релиза и bandwidth не ограничены заявленной квотой.
Это не повод добавлять всю библиотеку в историю Git: GitHub рекомендует
небольшие репозитории и блокирует обычные Git-файлы больше 100 MiB.

Записи можно скачивать по требованию и хранить в ограниченном клиентском кэше.
Размещение файлов не запускает голосовую модель: новый неизвестный текст
требует отдельного выполнения синтеза или предварительной генерации.

Источники:
- https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases
- https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github

## Hugging Face ZeroGPU

Актуальная документация разрешает бесплатному личному аккаунту с подтверждённой
почтой, возрастом старше 30 дней и хорошим статусом разместить до двух ZeroGPU
Spaces. Подписка PRO для этого случая не обязательна.

Квоты посетителей: 2 минуты GPU в сутки без авторизации; 5 минут для бесплатного
авторизованного аккаунта. Это время выполнения на GPU, не длительность готового
аудио. Есть очередь; это не выделенная видеокарта с непрерывной доступностью.
Повторное скачивание уже созданной записи должно идти из каталога/кэша.

Нужна адаптация: ZeroGPU поддерживает Gradio SDK, декоратор `spaces.GPU` и
PyTorch 2.8+ из поддерживаемого списка. Наш нынешний HTTP-воркер проверен с
PyTorch 2.6 и не может быть объявлен готовым ZeroGPU-приложением без переноса
и настоящей проверки. Нельзя обещать скорость, вместимость дневной квоты для
игровой сессии или стабильность всех запросов до замеров на ZeroGPU.

Обычные Gradio/Docker Spaces с CPU Basic, хотя аппаратный тариф не имеет
почасовой цены, сейчас требуют платного плана для создания. Не предлагать
их как гарантированно полностью бесплатный способ размещения.

Источники:
- https://huggingface.co/docs/hub/spaces-zerogpu
- https://huggingface.co/docs/hub/spaces-overview

## Следующий бесплатный шаг

Подготовить ZeroGPU-адаптер и проверить один новый квест Киро с утверждённым
эталоном, затем повтор из кэша. Публикация Space зависит от наличия подходящего
аккаунта и доступа к нему; эти данные сейчас не предоставлены. До этого можно
подготовить и проверить код локально. Продолжать накапливать готовые записи,
чтобы уменьшать зависимость от вычислительной квоты. При исчерпании квоты
сообщать об ожидании, сохраняя доступ к уже готовым записям.
