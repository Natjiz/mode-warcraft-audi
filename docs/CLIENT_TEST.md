# Проверка в WoW Circle 10.2.7

Пока не выполнена: доступ к игровому клиенту в облачной среде отсутствует.

1. Установить ZIP, убедиться, что клиент видит версию 0.2.0 без отметки
   устаревшего аддона. Включить `/console scriptErrors 1` на время проверки.
2. Войти с русским языком клиента. Проверить звук командой `/wca demo`. `/wca` открывает панель; перемещение,
   закрытие, повторное открытие и экспорт работают без Lua-ошибок.
3. Открыть обычный квест у NPC. Проверить заголовок, имя NPC, сообщение об
   отсутствии записи. В экспорте должны быть фактические ID, текст и `ruRU`.
4. Проверить события прогресса и сдачи этого квеста. У каждого этапа свой текст.
   Проверить автоматический квест без NPC: отсутствие NPC не должно давать ошибку.
5. Установить пакет с реальными короткими репликами для этого квеста,
   включая этап с двумя файлами. Перезапустить клиент. Звук идёт по порядку
   в канале «Диалоги», после последнего файла очередь завершается.
6. Повтор перезапускает реплику; «Стоп» её прекращает; закрытие диалога и
   переход к другому квесту прекращают старую запись. Другие звуки игры продолжаются.
7. Отключить «Авто»: новый диалог молчит, ручной повтор работает.
   После `/reload` настройка и накопленные тексты сохраняются.
8. Отключить сбор `/wca collect`, открыть новый квест: его нет в экспорте.
   Снова включить сбор и проверить появление текста.
9. Проверить отсутствие/повреждение файла пакета, отключённый канал «Диалоги»,
   конфликт двух пакетов. Ошибки воспроизведения должны быть видны, без зависшей очереди.
10. Проверить совместимость с используемыми на Circle модами квестового окна,
    если они установлены. Вернуть прежнее значение `scriptErrors` после проверки.
