# Проверка в WoW Circle 10.2.7 — версия 0.5.0

Облачные/Windows-тесты используют синтетический источник квеста. Настоящий
клиент Circle и физическое воспроизведение нужно проверить на компьютере игрока.
Эта страница описывает проверку разработчика; обычный запуск состоит из
открытия WarcraftAudi.exe, игры и квестового диалога.

1. При закрытой игре установить основной аддон 0.5.0 из комплекта и запустить
   WarcraftAudi.exe. Убедиться, что нет браузера, консоли и просьбы выделить область.
2. Войти в WoW в оконном режиме без рамки. Открыть известный озвученный квест
   (Киро 48313 или Акунда 50913). Внешний режим включён автоматически, короткий
   экранный сигнал появляется сам, текст поступает в программу и звучит без клика.
3. Проверить запуск программы после открытия диалога и игру после программы.
4. Переместить окно игры, сменить UI scale/разрешение или монитор. При следующем
   видимом сигнале программа должна восстановить передачу без ручной настройки.
5. Закрыть диалог/сменить квест: предыдущая запись останавливается; экранный сигнал
   исчезает после закрытия. Сворачивание/перекрытие игры останавливает звук через
   две секунды. Восстановление видимости не должно повторять уже завершённый запрос.
6. «Пауза» во внешнем окне не допускает позднего старта звука. «Продолжить»
   восстанавливает поиск. «Стоп озвучки» не требует нового включения всей программы.
7. Свернуть окно программы: работа продолжается. Закрыть его: работа заканчивается.
   Повторно открыть EXE во время работы: остаётся один экземпляр.
8. В настройках изменить громкость/лимит кэша. Поиск продолжается автоматически;
   явная пауза сохраняется. «Проба Акунды» не выдаётся за голос текущего NPC.
9. Проверить неизвестный квест: программа показывает отсутствие готовой записи,
   не запускает чужой голос. Для его генерации необходим отдельный сервер.
10. Проверить совместимость с установленными модами квестового окна и отсутствие
    Lua-ошибок. Для уже взятого задания выбрать его в журнале и выполнить `/wca read`.
