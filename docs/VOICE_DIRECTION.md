# Постановка голосов

Цель — выразительная русская фэнтезийная озвучка, соответствующая персонажу
и сцене. Выбор исполнителей/сервиса и производство записей — следующий этап.

Для каждого NPC закрепляется один голос и карточка: раса, возраст, тембр,
темп, манера речи, произношение имён. Боевой командир говорит собранно и веско,
учёный — любознательно, ветеран — сдержанно; каждому не требуется рычать.
Эмоция следует смыслу квеста, а не только расе персонажа. Не используйте
копирование голоса конкретного актёра как требование к генерации.

Текст квеста сохраняет смысл и последовательность оригинала. Ремарки,
интерфейсные маркеры, перечисления наград и служебные обозначения не читаются.
Если ремарка важна сюжету, она получает отдельно выбранный голос рассказчика.
До массовой генерации нужно утвердить несколько коротких проб для разных NPC:
произношение «Азерот», «Драктир», «Вальдраккен», паузы, ударения и отсутствие
роботизированного чтения. Составьте единый словарь имён по локализации клиента.

Длинные реплики делятся по предложениям. Каждый файл прослушивается целиком:
без пропущенных слов, обрезанных окончаний, щелчков, клиппинга и длинной тишины.
Громкость должна быть одинаковой между NPC; музыку и постоянный фон в речевые
файлы не встраивать, чтобы они сочетались со звуком игры. Экспорт — MP3 или
OGG Vorbis. Для первой вертикальной проверки достаточно одного реального
квеста со всеми тремя этапами, затем — небольшая зона, затем расширение каталога.
