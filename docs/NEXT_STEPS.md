# Следующий этап после Windows 0.5.0

3 ноября 2026 пользователь сообщил, что новая связка «нормально вроде работает».
Обычный запуск через EXE и автоматический поиск сохраняются. Голоса Акунды и
Киро уже приняты; они остаются эталонами для этих NPC.

## Цель

Игрок проходит новые квесты без ручного добавления записи разработчиком.
Открыл квест → готовая запись/кэш либо задача генерации → скачивание → звук.
Одна запись переиспользуется при повторных запросах и между игроками. В клиенте
остаётся ограниченный кэш, а не многогигабайтный пакет всех квестов.

## Что уже есть

- Windows-клиент, передача настоящего текста и сведений о NPC.
- Готовый каталог, контрольные суммы, локальный кэш 300 МБ.
- Серверный API, очередь, объединение одинаковых задач и серверный кэш.
- Qwen-воркер и постоянные голосовые эталоны на NPC; проверка настоящего синтеза
  на CPU проведена ранее. Это не измерение скорости на GPU и не публичный сервис.

## Что нужно сделать

1. Подключить постоянно доступный или временный тестовый сервер. Сначала измерить
   время генерации/повтора на реальном выбранном оборудовании. CPU здесь занимал
   минуты на новый текст; обещать мгновенную генерацию до GPU-проверки нельзя.
2. Добавить автоматическое подключение клиента к выбранному сервису. Игрок не
   должен вводить адрес сервера и ключи для обычного запуска. Адрес и механизм
   выдачи клиентского доступа готовятся после выбора размещения. Общий секрет
   нельзя помещать в публичный репозиторий или распространяемый ZIP.
3. Доработать сведения о новых NPC и выбор голоса: раса/вид, размер, пол, характер,
   затем устойчивый эталон на NPC. Нынешний автоматический генератор получает
   ограниченные сведения из клиента и не видит внешность по одному NPC ID.
   Если сведения неполны, соответствие образу не считается подтверждённым.
   Новые пробы остаются кандидатами, принятые эталоны не заменяются.
4. Проверить следующую цепочку заданий в игре: первый неизвестный текст создаётся
   сам, повтор берётся из кэша, NPC сохраняет голос, закрытие/смена квеста не
   допускает запоздавшего воспроизведения. Затем расширять охват.

## Ближайший проверяемый результат

Один ранее не опубликованный квест Киро проходит через внешний сервер целиком
с утверждённым голосом 0.4.2, без ручного ввода параметров сервера игроком.
Повтор не запускает синтез заново. После этого проверяется целая цепочка и
несколько NPC с различной внешностью. Это этап проверки автоматизации, а не
заранее подготовленная библиотека всех квестов игры.

## Размещение

Публичный сервер ещё не развёрнут. Пользователь предложил рассмотреть GitHub
и бесплатные серверы. Проверены текущие условия GitHub Releases и Hugging Face
ZeroGPU: [бесплатная схема и ограничения](FREE_HOSTING.md). Следующий кандидат
для бесплатного теста — адаптер ZeroGPU, а не обязательная аренда GPU.
Доступ к подходящему аккаунту пока не предоставлен. Платные ресурсы не подключены.

Реализация 0.6.0 подготовлена: [генерация по запросу](ON_DEMAND.md). Локальная
проверка Gradio и настоящего CPU-синтеза проведена; публикация и проверка
самого ZeroGPU ещё требуют подключённого HF-аккаунта.
