# «Природное лекарство», Киро — квест 48313

Пользователь перешёл к этому квесту после Акунды. Цель — проверить текущий
квест, сохранив отдельные характеры голосов NPC.

- Название: **«Природное лекарство» / Nature's Remedy**.
- Quest ID: **48313**.
- NPC: **Киро, 135154**, вульпера, Вол'дун / Зул'Аджин.
- Подтверждение цепочки:
  [WoW-Pro](https://github.com/Ludovicus-Maior/WoW-Pro-Guides/blob/master/WoWPro_Leveling/Retail/Horde/BFA_Voldun.lua).

- Независимая проверка названия и NPC:
  <https://nether.wowhead.com/tooltip/quest/48313?dataEnv=1&locale=7>,
  <https://nether.wowhead.com/tooltip/npc/135154?dataEnv=1&locale=7>.

Исходные тексты: `quests/kiro_48313_ruRU.json`.
Карточка пробного характера голоса: `quests/kiro_voice_design.json`.
Проба **0.4.1 отвергнута пользователем**: голос оказался слишком басовым
для внешности Киро. Её записи сохранены только как история и помечены
`status: rejected`; сборщик не включает их в активный каталог.

Замена **0.4.2** задаёт лёгкий мужской тенор, подвижную разговорную подачу
и немного носового резонанса. Направление хранится и в карточке NPC, и в
`AGENTS.md`; массивный бас Акунды не является общим стилем проекта.
Проба — `downloads/Kiro-character-voice-0.4.2.mp3`, новые реплики —
`assets/kiro_light_streamed`, версия голоса — `kiro-light-candidate-0.4.2`.
У новых файлов отдельные URL, чтобы старый кэш не выдавал отвергнутый дубль.

Акустическая проверка пробы (librosa pYIN): медиана основного тона около
223 Гц против 134 Гц у отвергнутой пробы Киро и 94 Гц у эталона Акунды.
Whisper Base распознал весь текст новой пробы без расхождений. Эти проверки
подтверждают смену регистра и дают контроль текста; они не заменяют
прослушивание и не подтверждают художественное соответствие персонажу.
Пользователь принял голос **0.4.2** («пойдет»). В карточке NPC стоит
`approved: true`; этот эталон сохраняется для следующих реплик Киро.
Исторический ID `kiro-light-candidate-0.4.2` остаётся прежним для совместимости
каталога и кэша.

В готовых репликах медиана основного тона 216–232 Гц. Длинное описание
записано по фразам с тем же эталоном; подсказки в виде знаков ударения
отбракованы. Есть отдельный дубль фразы про яд скорпида с обычным написанием.
Отчёт машинных проверок: `assets/kiro_light_streamed/checks.json`.
Распознавание слов «скорпида»/«вены» неоднозначно; точность дикции не объявляется
подтверждённой только на основании ASR.

Для чтения из журнала добавляются явные записи с NPC 0 только для известных
описаний, у которых единственный записанный голос. Если один и тот же текст
одного задания озвучен разными персонажами, голос для журнала не угадывается.

## Обновление программы игрока

Переустановка Windows-программы 0.4.0 не требуется: неизвестный ей квест
запускает загрузку текущего небольшого каталога с GitHub. Если программа уже
пыталась обновить его недавно, завершите её кнопкой «Завершить программу» и
снова запустите `Start.bat` — это сбросит интервал проверки каталога.

После перезапуска нажмите в программе «Запустить». Выберите квест в журнале
и выполните `/wca read`, либо откройте нужный этап диалога у Киро. Индикатор
должен быть откалиброван и виден.

В программе 0.4.0 кнопка «Проверить голос» и команда `/wca demo` запускают
фиксированную пробу Акунды. Голос текущего NPC проверяйте через его диалог
или `/wca read` с выбранным заданием.
Сравнение текста строгое: несовпадающий текст Circle не получит случайную
запись. При несовпадении нужен реальный текст из клиента для следующей правки.

Это расширение готового каталога для текущей проверки; публичный сервер
генерации всех неизвестных квестов по-прежнему не развёрнут, как и было
согласовано. Голос Киро 0.4.2 принят пользователем; точное совпадение всех текстов Circle
и работа новых этапов квестов проверяются отдельно.
