# Характер голоса: Акунда

Пользователь отверг пробу 0.2.1: голос слишком человеческий и недостаточно
грубый для внешности Акунды. Требование — голос огромного громового ящера,
с тяжёлым грудным резонансом и грубой фактурой, но с понятными словами.

Новая проба создана моделью **Qwen3-TTS VoiceDesign**, которая принимает
описание характера голоса. Это отдельный эксперимент: прежние пакеты аддона
не заменяются автоматически. В обработке пробы используется только выравнивание
громкости: шероховатость и глубину должна создать сама голосовая модель.
Нет дополнительного понижения записи, эха, шумовых слоёв и перегруза.

Карточка персонажа и точная реплика: `quests/akunda_voice_design.json`.
В ней указан NPC 128152, русский язык и описание огромного древнего существа:
густой низкий мужской голос, грубая вибрирующая фактура горла, спокойная власть,
чёткая артикуляция. Не используется голос конкретного актёра или запись человека.
Реплика взята из уже проверенного текста выбранного квеста.

## Результат и проверки

Файл `downloads/Akunda-character-voice-0.3.0.mp3` длится 8,8 секунды.
Синтез занял около 126 секунд на CPU. SHA-256 весов проверены перед загрузкой;
выходной MP3 полностью декодирован FFmpeg. В соседнем JSON сохранены параметры,
текст, хеши и длительность. Копии модели в Git не публикуются.

Независимое распознавание `openai/whisper-base` восстановило обе фразы, но
написало «примей» вместо «прими». Это не доказывает ошибку произношения модели,
однако это слово требует проверки на слух. Результат распознавания сохранён
рядом с пробой. Разборчивость и соответствие внешности не считаются утверждёнными.

## Повторение

Отдельное окружение не изменяет рабочую цепочку Silero:

```sh
python3 -m venv /workspace/.warcraft-voice-design-venv
/workspace/.warcraft-voice-design-venv/bin/python -m pip install \
  --index-url https://download.pytorch.org/whl/cpu \
  'torch==2.6.0+cpu' 'torchaudio==2.6.0+cpu'
/workspace/.warcraft-voice-design-venv/bin/python -m pip install \
  'qwen-tts==0.1.1' 'numpy==2.2.6' 'scipy==1.15.3'
```

В текущей машине окружение использует установленный CPU PyTorch через `.pth`
к `/workspace/.warcraft-audi-venv/lib/python3.12/site-packages`, чтобы не хранить
его вторую копию. Установки по рецепту выше достаточно на новой машине.

Модель хранится вне репозитория в
`/workspace/.warcraft-audi-models/qwen3-voice-design`. Загружать её следует
через официальный `huggingface_hub.snapshot_download` с параметрами:

- repo: `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`;
- revision: `5ecdb67327fd37bb2e042aab12ff7391903235d3`;
- allow_patterns: `*.json`, `*.txt`, `*.safetensors`, `speech_tokenizer/*`;
- max_workers: `2`.

Модель и токенизатор занимают около 4,21 GiB. В текущей машине доступны 4 CPU
и 32 GiB RAM; используется bfloat16 с SDPA на CPU, без Flash Attention.
Скрипт до загрузки сверяет SHA-256 обоих файлов safetensors с LFS-метаданными
того же закреплённого коммита. TLS и контрольные суммы не отключаются.

```sh
/workspace/.warcraft-voice-design-venv/bin/python tools/design_akunda_voice.py \
  --output downloads/Akunda-character-voice-0.3.0.mp3
```

Скрипт сохраняет рядом JSON с карточкой персонажа, хешами, длительностью
и параметрами модели. Старые пробы не перезаписываются. Он отклоняет пустой,
нечисловой/тихий результат и генерацию, упёршуюся в лимит длины; готовый MP3
целиком декодируется FFmpeg. Эти проверки не подтверждают художественное
соответствие внешности или качество произношения — их необходимо оценить на слух.
Прежде чем переносить голос на все реплики NPC, нужно утвердить звучание и
обеспечить постоянство тембра между репликами.
