# Аддон и внешняя программа — прототип 0.4.0

## Что сделано

Аддон передаёт реальный текст открытого квеста, ID, этап, пол персонажа и
доступные сведения о NPC через небольшой экранный индикатор. Внешняя программа
считывает его, скачивает или запрашивает запись, проверяет SHA-256, воспроизводит
звук и хранит ограниченный LRU-кэш (по умолчанию 300 МБ).

У сервера есть очередь генерации и общий кэш. Одновременные одинаковые запросы
не создают несколько заданий. Ключ зависит от текста, NPC, языка, этапа, пола
и версии голосовой библиотеки. Изменённый на Circle текст не получает случайную
запись от другого текста. Имя игрока перед передачей серверу заменяется либо
опускается в обращении; исходный снимок экрана никогда не отправляется наружу.

Голос Акунды берётся из утверждённой пользователем пробы 0.3.0. Реплики
создаются через Qwen Base с её голосовым эталоном, а не новым случайным тембром.
Для неизвестного NPC сервер один раз создаёт эталон из доступных сведений о
расе/типе/поле, сохраняет его и использует дальше. **Это только автоматический
кандидат:** возраст, характер и внешность не всегда доступны через API игры.
Особым персонажам нужны проверенные карточки, как `voices/npcs/128152.json`.
Система не утверждает, что автоматически видит и точно оценивает внешность NPC.

## Windows 10/11 x64

Скачайте `WarcraftAudi-Companion-0.4.0-Windows.zip` из `downloads` и полностью
распакуйте. В комплекте официальный CPython и готовые Windows-зависимости;
моделей генерации и большого каталога звуков на компьютере игрока нет.

1. Закройте игру. Скопируйте `AddOns/WarcraftAudi` из комплекта в
   `Interface/AddOns` клиента, заменив основной аддон.
2. Запустите `Start.bat`; откроется окно управления в обычном браузере.
   Окно программы можно свернуть, закрытие браузерной вкладки её не завершает.
3. Нажмите «Проверить голос». Скачается утверждённая проба Акунды.
4. В игре выполните `/wca companion`. Появится индикатор с цветными углами.
5. В программе нажмите «Выделить индикатор на экране» и за 3 секунды
   переключитесь в WoW. Подождите снимка, вернитесь в программу, обведите
   индикатор целиком и сохраните область. Затем нажмите «Запустить».
6. Вернитесь в игру и откройте квест. Повтор/стоп и автозапуск управляются
   привычной панелью аддона. Внешний режим отключает дублирование звука в игре.

Для задания без диалога с NPC выберите его в журнале и введите `/wca read`.
Программа получит описание выбранного задания; если говорящий неизвестен,
используется отдельный рассказчик. Асинхронная загрузка проверяет, что выбор
не сменился. Автоматические события всех разновидностей мировых заданий
отдельно не проверены; ручное чтение доступного текста журнала — запасной путь.

Для первой проверки используйте оконный режим без рамки. Индикатор должен быть
видим: при его пропадании программа прекращает звук примерно через две секунды.
Его можно передвинуть мышью, но после перемещения/смены разрешения нужна новая
калибровка. Автозапуск выключен — запись можно подготовить без воспроизведения.
Для выхода из программы нажмите «Завершить программу» или закройте её консоль.
Повторный запуск открывает уже запущенную программу вместо второго проигрывателя.

Настройки и кэш: `%LOCALAPPDATA%/WarcraftAudi`. Ключ сервера в файл не сохраняется.
Звук воспроизводится программой через системное устройство, не через канал
«Диалоги» WoW; громкость регулируется в программе. Разрешения на изменение памяти
игры, чтение её процесса, модификацию клиента или отправку клавиш не используются.

## Что сейчас доступно без собственного сервера

Лёгкий каталог `companion/catalog.json` содержит только существующие записи:
утверждённую пробу и новые реплики Акунды по этому эталону. Они доступны через
GitHub и скачиваются по необходимости. Готовых записей для остальных квестов нет.
Если текст в клиенте отличается от текста каталога, программа покажет отсутствие
записи вместо проигрывания неподходящей реплики.

**Публичный сервер генерации ещё не развёрнут.** Для новых квестов в настройках
нужен его HTTPS-адрес. Код сервера и очередь проверены локально; выбор хостинга,
оплата GPU и выдача доступа — отдельный незавершённый этап. ZIP не обещает
озвучивать все неизвестные квесты без подключения такого сервера.

## Запуск клиента из исходников

```sh
python -m pip install -r companion/requirements.txt
python -m companion
```

Для Linux нужны разрешение на захват экрана и доступный X11-дисплей/совместимый
режим. Wayland и macOS в этой версии отдельно не проверены.

## Проверки и границы доказательств

- Настоящий Lua 5.1 код аддона -> его отрисованные пиксели -> декодер Python:
  русский многостраничный текст, масштабы 0,75/1/1,5, потеря/повтор/повреждение
  страниц, контрольные суммы и отсутствие повторного звука в клиенте.
- Реальные HTTP-запросы: очередь, авторизация, повторное использование записи,
  скачивание с контролем целостности и остановка при запоздавшем ответе.
- Реальный сервер Qwen: генерация по голосу Акунды, скачивание и декодирование
  клиентом. В проверке короткая реплика заняла 51,8 с на CPU; повтор — 0,029 с.
  Это измерение одной реплики, а не гарантия времени остальных запросов.
- Отдельный синтетический NPC, отсутствующий в карточках: сервер действительно
  создал голосовой эталон и озвучил две разные реплики. Хеш эталона между ними
  не изменился. Эти тестовые реплики не добавлены в публичный каталог.
- Браузер Chromium: выбор области на **синтетическом экране**, приём сообщения,
  скачивание настоящего аудио, декодирование miniaudio, пауза, настройки,
  очистка кэша и завершение без ошибок JavaScript.
- Windows CPython: SHA-256 и подпись Sigstore Python release manager проверены;
  Windows wheels сверены с опубликованными SHA-256 PyPI.

В облаке нет настоящего Windows-клиента WoW и аудиоустройства пользователя.
**Windows-запуск, захват реального игрового окна, слышимый вывод и качество
всех сгенерированных голосов ещё требуют проверки на компьютере игрока.**
Нельзя приравнивать синтетический экранный тест к уже проверенной связи с WoW.

Архитектура индикатора: 208×112 пикселей, 64×32 двоичные ячейки, кадр 256 байт,
232 байта данных на страницу, до 128 страниц, смена каждые 0,12 с. В каждом
кадре есть ID сеанса/запроса, номер страницы и Adler-32 кадра/сообщения.
Обычные SavedVariables не используются как канал реального времени.

Разработческие проверки: `python -m unittest discover -s tests -v`.
Браузерный тест использует `tests/desktop_fixture.py` и
`tests/browser_smoke.js` (Playwright 1.55.0). Фикстура явно имитирует экран и
декодирует настоящее аудио, но не воспроизводит его на физическом устройстве.
