# Warcraft Audi 0.5.0

## Запуск

Разово распакуйте комплект и при закрытой игре замените основной аддон папкой
`AddOns/WarcraftAudi` из ZIP. Затем обычный запуск: **WarcraftAudi.exe → игра →
диалог квеста**. Можно сначала открыть игру. Окно программы можно свернуть;
его закрытие останавливает программу. `Start.bat` оставлен для диагностики.

Браузер, локальная веб-страница, выделение области, сохранение калибровки,
кнопка «Запустить» и `/wca companion` не входят в обычный запуск.
Внешний режим включается при установке и однократном обновлении старых настроек.
Дальнейшее явное отключение командой `/wca companion` сохраняется.

## Почему на экране остаётся небольшой сигнал

Обычный WoW-аддон не может открывать сетевые подключения и записывать произвольный
поток файлов во время игры. SavedVariables сохраняются при выходе или `/reload`,
поэтому они не подходят для озвучки текущего диалога без дополнительных действий.

Аддон автоматически показывает текст в виде небольшого блока пикселей во время
диалога. В версии 0.5 он меньше, не перехватывает мышь и исчезает после закрытия
диалога. Программа сама находит его; выделять или настраивать ничего не нужно.
Сигнал должен оставаться видимым, поэтому используется оконный режим без рамки.
Если он перекрыт или игра свёрнута, текущая озвучка останавливается примерно через
две секунды. После возвращения к игре программа продолжает искать автоматически.

## Окно Windows

Окно создаётся через Win32 API, без браузера, WebView и отдельного веб-сервера.
Ожидание игры начинается при запуске. Есть «Пауза», «Стоп озвучки» и необязательные
«Настройки»: громкость, кэш, сервер и ключ. Настройки сохраняются без нового
нажатия запуска; явная пауза сохраняется. «Проба Акунды» подписана именем NPC,
чтобы не путать её с голосом текущего персонажа.

Новый `WarcraftAudi.exe` — маленький launcher, запускающий комплектный `pythonw.exe`
без консоли. Повторный запуск открывает существующее окно. Ни Python, ни права
администратора для пользователя не нужны. Наш launcher не подписан; подпись
официального CPython и SHA-256 Windows wheels проверяются при сборке.

## Автоматическое получение текста

Поиск перебирает мониторы, в том числе с отрицательными координатами, находит
три маркера и проверяет контрольную сумму полного кадра. Похожие цветные элементы
не принимаются за текст. После первого обнаружения читается только маленький
участок. При перемещении, изменении DPI/масштаба или разрешения поиск повторяется.
Старые ручные координаты из settings.json игнорируются.

Пакеты по 256 байт включают сессию, порядковый номер, страницу и две контрольные
суммы. Многостраничный текст собирается до отправки. Запоздавшие кадры после паузы
и старые страницы не запускают звук. Изображения не сохраняются и не отправляются.

## Озвучки и хранение

Готовые записи скачиваются по точному тексту/NPC/этапу, проверяются SHA-256 и
попадают в LRU-кэш на 300 МБ. Играющий файл закреплён до завершения. Доступны
Акунда и «Природное лекарство» (48313) от Киро; оба эталона приняты пользователем.
Другим NPC нужны свои голоса под их внешний образ. Отклонённый бас Киро исключён
из активного каталога. «Все квесты» без готовых записей требуют работающего сервера
генерации; публичный сервер пока не развёрнут. Код очереди и серверного API
находится в `server/README.md` и `companion/warcraft_audi/server.py`.

Кэш и настройки: `%LOCALAPPDATA%/WarcraftAudi`. Ключ сервера хранится в памяти.
Ошибки запуска пишутся в `app.log` в этой папке.

## Проверки и пределы

Локальные тесты исполняют настоящий Lua 5.1, рисуют его пиксели, декодируют
многостраничный текст при разном масштабе. Дополнительные проверки покрывают
второй монитор, запуск программы раньше игры, перемещение/масштабирование,
ложные маркеры, перекрытие, паузу во время захвата и миграцию настроек.

Windows-проверка `.github/workflows/windows.yml` создаёт настоящее окно Win32,
показывает тестовый пиксельный сигнал, читает его через Windows mss и скачивает
озвучку Киро с проверкой SHA и декодированием miniaudio. Это синтетический источник
текста: тест не запускает WoW Circle и не проверяет физическое звуковое устройство.
Актуальный результат конкретного запуска нужно смотреть в GitHub Actions;
наличие workflow само по себе не означает успешную проверку.
