Программа озвучки для WoW Circle 10.2.7

Подключаюсь…

Первое подключение

  1. Установите основной аддон из комплекта и введите в игре /wca companion.
  2. Появится чёрно-белый прямоугольник с тремя цветными углами. Не закрывайте его другими окнами.
  3. Нажмите кнопку ниже и обведите весь прямоугольник на снимке экрана.
  4. Нажмите «Запустить» и откройте квест в игре.

После нажатия за 3 секунды переключитесь в WoW. Подождите снимка и вернитесь сюда для выделения.

Индикатор можно перетащить мышью в игре. После перемещения или изменения разрешения выделите его снова. Для первой проверки используйте оконный режим без рамки.

Обведите индикатор вместе с цветными углами. Достаточно выделить область чуть больше него.

Настройки

Ключ хранится только до закрытия программы. Внешнему серверу передаются текст квеста и сведения о NPC. Изображение экрана обрабатывается на этом компьютере и на сервер не отправляется.

Без сервера доступны только уже опубликованные записи. Для новых квестов нужен работающий сервер генерации; первый запрос может занять несколько минут.
